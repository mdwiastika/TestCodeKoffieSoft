## Step 4 & 5: Models, Migrations, Seed, and Pytest Suite
- **Actions Taken**:
  - Implemented SQLAlchemy 2.0 models `Member` (`team_members`) and `Task` (`tasks`) with constraints:
    - NOT NULL on required fields.
    - UNIQUE and indexed on `team_members.email`.
    - FK `tasks.assignee_id -> team_members.id` with `ondelete="SET NULL"`.
    - CheckConstraints for status (`To Do`, `In Progress`, `Done`) and priority (`Low`, `Medium`, `High`).
    - Indexes on `tasks.status`, `tasks.assignee_id`, `tasks.due_date`.
    - Timezone-aware UTC `created_at`.
  - Configured Alembic with `target_metadata = Base.metadata` and dynamic settings URL. Autogenerated and executed migration `13e9c867712c_create_team_members_and_tasks_tables.py` on both dev and test databases (`alembic upgrade head`).
  - Implemented Pydantic v2 schemas with `ConfigDict(from_attributes=True)` and computed field `is_overdue` (`due_date < today and status != 'Done'`).
  - Implemented services layer: `MemberService`, `TaskService` (combinable filters for search, status, priority, assignee_id), `DashboardService` (efficient single SQL CASE query).
  - Implemented thin REST routers for `/members`, `/tasks`, `/dashboard`.
  - Created and ran `seed.py` loading 4 realistic team members and 8 tasks (including overdue, unassigned, and past-due Done tasks).
  - Created 20 comprehensive pytest tests across `test_members.py`, `test_tasks.py`, and `test_dashboard.py` verifying full CRUD, 404, 409, 422, combinable filters, and overdue exclusion for Done tasks. All 20 tests pass.
- **Bugs Encountered & Fixed**:
  - `email-validator` was needed by Pydantic's `EmailStr`. Installed `email-validator==2.3.0` and pinned it to `requirements.txt`.
  - RFC validation: `.local` TLD in seed/tests was rejected by `email-validator` as a special-use mDNS domain; updated test fixtures and seeds to use valid domains like `@koffiesoft.com` and `@example.com`.
  - Pytest module resolution: Created `pytest.ini` with `pythonpath = .` so `app` is imported reliably.

## Step 7 & 8: Frontend Architecture, Taste Skill Inspection & E2E Verification
- **Actions Taken**:
  - Scaffolded React 19 + TypeScript + Vite frontend in `/frontend` with its own isolated Git repository.
  - Installed and configured Tailwind CSS, shadcn/ui inspired primitives, Lucide icons, TanStack Query v5, and React Hook Form + Zod.
  - Implemented:
    - `Dashboard` page with 5 KPI summary cards (Total, To Do, In Progress, Done, Overdue with red accent), and an "Immediate Attention Items" actionable list.
    - `Tasks` page with desktop table, mobile card list (< 768px), desktop inline filter bar, mobile slide-over filter sheet/drawer, Zod validated task dialog, and delete confirmation modal.
    - `Members` page with member list, avatar initials, add/edit member dialog, and delete confirmation warning explaining `ON DELETE SET NULL`.
    - `ToastProvider` for instant feedback on success/failure actions.
    - Four states implemented across all views: Loading (skeletons), Empty (icon + action), Error (retry button), Success (toasts).
  - Built production distribution with `npm run build` (compiled in ~500ms with 0 errors and 0 warnings).
  - Executed `design-taste-frontend` inspector tool (`inspect.mjs --app`) at 1280px, 768px, and 360px widths.
  - Captured and inspected live browser screenshot renderings at all three responsive widths.
- **Bugs Encountered & Fixed**:
  - TypeScript build error: `allowImportingTsExtensions` flag caused `import App from './App.tsx'` to fail build. Removed extension to standard `import App from './App'`. Added `"ignoreDeprecations": "6.0"` for TS 5.8+ `baseUrl`.
  - CORS and IP resolution: Frontend `localhost:8000` vs `127.0.0.1:8000`. On Windows, `localhost` resolved to IPv6 `::1`, causing browser fetch to drop connection to IPv4 Uvicorn. Updated CORS allowed origins to include `http://127.0.0.1:5173` and set `VITE_API_URL=http://127.0.0.1:8000`, binding Uvicorn to `0.0.0.0:8000`.
  - Design inspection metrics:
    - Fixed uppercase micro-labels on KPI cards to sentence case (`text-sm font-medium`).
    - Removed tinted circular badges around action icons (`[icon-chips]`).
    - Added semantic `h1` header to eliminate `[no-title]` violation.
    - Adjusted mobile navigation button padding to guarantee > 20px margin on 360px viewports (`[edge-text]`).
    - Inspector returned `0 FAIL, measurements pass`.
